# Natural Language Processing

Natural Language Processing, or NLP, focuses on enabling computers to work with human language.

## Common Tasks

NLP systems can perform tasks such as text classification, sentiment analysis, summarization, translation, and question answering.

## Text Processing

Before a model processes text, the input may need to be cleaned and converted into a representation that the model can use.

Modern NLP systems commonly use tokenization and language models to understand relationships between words and sentences.

## Applications

NLP is used in chatbots, search systems, document processing, customer support, and other applications that work with written or spoken language.
