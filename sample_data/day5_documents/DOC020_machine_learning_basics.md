# Machine Learning Basics

Machine learning allows software systems to learn patterns from data and use those patterns to make predictions or decisions.

## Training Data

Training data contains examples used by a machine learning algorithm to learn.

The quality of the training data can strongly affect the resulting model.

## Features

Features are the pieces of information used by a model to make a prediction.

For example, a model predicting house prices might use location, size, and number of rooms as features.

## Classification

Classification assigns an input to one of several categories.

Examples include identifying an email as spam or classifying a customer message as a complaint, feedback, or inquiry.

## Evaluation

A model should be evaluated using data that was not used directly for training.

Common evaluation measures include accuracy, precision, recall, and F1 score.

## Practical Considerations

A machine learning model should not be judged only by one metric. The evaluation method should match the actual problem and its consequences.
